## ۱. فاز ۰ — زیرساخت SMS «کامل و منتظر سرویس»  (اولویت)

**هدف:** وقتی سرویس مخابرات خریداری شد، فقط چند متغیر env را پر کنیم؛ هیچ کد business تغییر نکند. در dev/استیج هنوز `mock` می‌ماند.

**وضعیت:** ✅ **انجام شد** (۱۸ اکتبر ۲۰۲۶) — typecheck سبز، ۹ تست SMS + ۲۰۲ تست واحد پاس، بدون رگرسیون.

### ۱.۱ اینترفیس و متن پیام
- [x] اینترفیس `SmsProvider` **دست‌نخورده ماند**؛ قالب متن دری در لایهٔ provider نگه داشته شد: `providers/sms/sms-message.ts` + متغیر `SMS_MESSAGE_TEMPLATE` (placeholder `{code}` و `{purpose}`)

### ۱.۲ آداپتور HTTP (vendor-agnostic)
- [x] `providers/sms/http-sms.provider.ts` **(جدید)** — پیاده‌سازی `SmsProvider`
  - `POST` به `SMS_GATEWAY_URL` با هدر auth قابل‌پیکربندی و بدنهٔ `{to, message, sender}`
  - timeout (`AbortSignal.timeout`) + retry با backoff نمایی + پرتاب خطا در شکست (خود `VerificationService` → `OTP_DELIVERY_FAILED` و ابطال کد را از قبل دارد)
- [x] نقطهٔ تعویض vendor: اگر vendor انتخابی شکل فرق کرد، فقط یک کلاس آداپتور پشت همان `SmsProvider` (بدون تغییر business logic) — مستند در `README.md`

### ۱.۳ ثبت و سوییچ
- [x] `providers/sms/sms.module.ts` — افزودن `HttpSmsProvider` + `case 'http': return http;`
- [x] `config/env.schema.ts` — متغیرهای جدید (اختیاری؛ در `http` اجباری با `superRefine`): `SMS_GATEWAY_URL`, `SMS_GATEWAY_API_KEY`, `SMS_GATEWAY_API_KEY_HEADER`, `SMS_GATEWAY_API_KEY_PREFIX`, `SMS_GATEWAY_SENDER`, `SMS_GATEWAY_TIMEOUT_MS`, `SMS_GATEWAY_MAX_RETRIES`, `SMS_MESSAGE_TEMPLATE`
- [x] `config/configuration.ts` + `config/config.types.ts` — namespacing (`providers.smsHttp`) و تایپ متغیرها

### ۱.۴ محافظ تولید
- [x] fail-fast: در `production` اگر `SMS_PROVIDER=mock` باشد → خطا در فکتوری `SmsModule`؛ و اگر `SMS_PROVIDER=http` بدون URL/کلید باشد → خطای `validateEnv` در bootstrap

### ۱.۵ تست و مستند
- [x] تست واحد `HttpSmsProvider` + `renderSmsMessage` (HTTP موک‌شده، ۹ تست) — `providers/sms/http-sms.provider.spec.ts`

- [x] `.env.example` + `README.md` (جدول کامل متغیرها + runbook ادغام SMS هنگام خرید)

**معیار خروج:** ✅ `SMS_PROVIDER=http` فقط با env کار می‌کند؛ `mock` در production رد می‌شود؛ تست سبز.

- [x] `src/app/sitemap.ts` **(جدید)** — فقط URL آگهی‌های **ACTIVE** (فید عمومی = ACTIVE فروشندهٔ ACTIVE) + دسته‌های ACTIVE + صفحات ثابت؛ با `revalidate=3600` و سقف پیمایش. `/search`، `/admin`، `/account` و storefront فروشنده (تا فاز ۲) خارجند.
