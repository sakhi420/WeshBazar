# ممیزی و طراحی صفحات راهنما، درباره ما، نکات ایمنی، مرکز راهنمایی و تماس با ما

## هدف

ممیزی واقعی وضعیت صفحات اطلاعاتی/پشتیبانی که از فوتر لینک شده‌اند و طراحی
معماری محتوای آن‌ها — بدون بازنویسی گستردهٔ صفحات در این مرحله (مطابق بند ۹
دستور کار).

## محدوده

- پنج مورد فوتر: «راهنما» (عنوان گروه) + چهار لینک «درباره ما»، «نکات ایمنی»،
  «مرکز راهنمایی»، «تماس با ما».
- مسیرهای: `/about`, `/help/safety`, `/help`, `/contact`.

## وضعیت ممیزی

- **ممیزی و طراحی: انجام شد.** (این سندها)
- **پیاده‌سازی گستردهٔ محتوا: در انتظار تأیید مالک.** (بند ۹)

## ترتیب مطالعه

1. `01-current-state.md` — وضعیت واقعی فوتر و صفحات.
2. `02-criteria-and-gap-analysis.md` — مقایسهٔ وضعیت با معیارها.
3. `03-target-design-and-roadmap.md` — معماری محتوا و نقشهٔ اجرا.
4. `findings.md` — ایرادهای تأییدشده.
5. `criteria-register.json` — معیارهای قابل پیگیری.
6. `review-inventory.md` — فهرست فایل‌ها/لینک‌ها/تست‌ها.
7. `research-sources.md` — منابع بررسی‌شده.

## خلاصهٔ تصمیم‌ها

1. **«راهنما» صفحه نیست؛ عنوانِ گروه فوتر است.** محتوای «راهنمای شروع و استفاده»
   باید در «مرکز راهنمایی» (`/help`) به‌عنوان بخش «شروع سریع» ادغام شود تا دو
   صفحهٔ هم‌معنا به‌وجود نیاید.
2. **اطلاعات تماس اختراع نمی‌شود.** `تماس با ما` فقط از مسیرهای واقعی (گزارش
   آگهی + مرکز راهنمایی) استفاده می‌کند؛ وجود کانال پشتیبانی رسمی نیاز به تأیید
   مالک دارد.
3. **صفحات فعلی اسکلت حداقلی هستند** (برای رفع 404 در ممیزی فوتر ساخته شدند) و
   محتوای عمقی آن‌ها در فاز بعد پیاده می‌شود.
