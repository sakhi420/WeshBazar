## 2. صفحات

### درباره ما — `/about`

- وضعیت: **موجود** (Server Component، محتوای ثابت).
- محتوا: دو پاراگراف. می‌گوید «بستری ساده و رایگان برای خرید و فروش» و «بدون
  واسطه» — ولی محدودهٔ «نگهداری پول/پرداخت/ارسال/حل اختلاف» را صریح نمی‌گوید.
- متادیتا: فقط `title` + `canonical`.

### نکات ایمنی — `/help/safety`

- وضعیت: **موجود**.
- محتوا: چهار نکته برای خریدار + چهار نکته برای فروشنده. ذکر «آگهی را گزارش دهید»
  بدون لینک به مسیر گزارش.
- متادیتا: فقط `title` + `canonical`.

### مرکز راهنمایی — `/help`

- وضعیت: **موجود**.
- محتوا: سه کارت موضوعی (ایمنی → `/help/safety`، جست‌وجو → `/search`، ثبت آگهی
  → `/sell`). فاقد راهنمای گام‌به‌گام شروع.
- متادیتا: فقط `title` + `canonical`.

### تماس با ما — `/contact`

- وضعیت: **موجود**.
- محتوا: دو کارت («گزارش آگهی تخلف» و «مرکز راهنمایی»). هیچ شماره/ایمیل/شبکهٔ
  اجتماعی اختراعی نیست.
- متادیتا: فقط `title` + `canonical`.
