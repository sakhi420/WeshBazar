# 03 — Target Design & Roadmap

## 1. معماری محتوا و تفاوت صفحات

پایان‌نامهٔ اصلی: «راهنما» **صفحه نیست**؛ عنوان گروه فوتر است. برای جلوگیری از
دو صفحهٔ هم‌معنا، «راهنمای شروع و استفاده» داخل «مرکز راهنمایی» ادغام می‌شود.

### الف) درباره ما — `/about`

- **هدف:** توضیح اینکه وش‌بازار چیست.
- **مخاطب:** کاربر جدید/کنجکاو.
- **پرسش اصلی:** «وش‌بازار چیست و چه کاری برای من می‌کند؟»
- **محتوای لازم:** چیست؛ هدف؛ چطور استفاده می‌شود (جست‌وجو/ثبت/تماس)؛ محدودهٔ
  صریح (واسطهٔ پول/پرداخت/ارسال/حل اختلاف نیست).
- **CTA:** «شروع جست‌وجو» → `/search`؛ «مرکز راهنمایی» → `/help`.
- **محدودیت:** بدون شماره/ایمیل/گواهی/آمار ساختگی.
- **تصمیم مالک:** بیانیهٔ رسمی مأموریت + هر آمار معتبر.

### ب) نکات ایمنی — `/help/safety`

- **هدف:** کاهش ریسک معامله.
- **مخاطب:** خریدار و فروشنده.
- **پرسش اصلی:** «چطور امن معامله کنم؟»
- **محتوای لازم:** برای خریدار (بررسی کالا، معاملهٔ حضوری، رد پیش‌پرداخت، قیمت
  مشکوک)؛ برای فروشنده (توضیح صادقانه، تحویل پس از اطمینان)؛ علائم خطر (قیمت پایین،
  عجله، پیش‌پرداخت، لینک ناشناس)؛ «چه زمانی متوقف شوم» + مسیر گزارش.
- **CTA:** «گزارش آگهی مشکوک» + «مرکز راهنمایی».
- **محدودیت:** بدون ادعای ضمانت مالی/بازپرداخت/حل اختلاف؛ بدون ادعای قانونی افغانستان.

### ج) مرکز راهنمایی — `/help`

- **هدف:** پاسخ به «چطور …؟»
- **مخاطب:** همهٔ کاربران.
- **پرسش اصلی:** «چطور شروع کنم و از برنامه استفاده کنم؟»
- **محتوای لازم:** بخش «شروع سریع» (پیدا کردن ← بررسی ← تماس ← ثبت آگهی ← مدیریت
  حساب) + کارت‌های موضوعی + پیوند به ایمنی/گزارش/تماس.
- **CTA:** هدایت به موضوع/مرحله.
- **تصمیم مالک:** ندارد.

### د) تماس با ما — `/contact`

- **هدف:** «اگر مشکل دارم کجا بروم؟»
- **مخاطب:** کاربر با مشکل یا گزارش.
- **پرسش اصلی:** «چطور مشکل را گزارش یا حل کنم؟»
- **محتوای لازم:** گزارش آگهی (مسیر واقعی)؛ مرکز راهنمایی؛ (در صورت تأیید) کانال
  پشتیبانی رسمی.
- **CTA:** لینک به `/help` و گزارش آگهی.
- **تصمیم مالک:** **لازم است** — وجود/نبود کانال پشتیبانی رسمی.

## 2. ترتیب پیاده‌سازی و وابستگی‌ها

| گام | کار | وابستگی |
| --- | --- | --- |
| 1 | `about/page.tsx` — جملهٔ محدوده + CTA | متن مأموریت مالک (اختیاری) |
| 2 | `help/page.tsx` — بخش «شروع سریع» | مسیرهای موجود `/search`, `/sell`, `/account` |
| 3 | `help/safety/page.tsx` — علائم خطر + لینک گزارش | `ReportDialog` موجود |
| 4 | `contact/page.tsx` — انعکاس تصمیم کانال پشتیبانی | **تصمیم مالک** |
| 5 | افزودن `description`/OG به هر ۴ صفحه | ندارد |
| 6 | تست لینک/محتوا برای ۴ صفحه | ندارد |

## 3. معیارهای پذیرش

- [ ] هر ۴ صفحه `description` فارسی دارند و مسیرها 404 نیستند.
- [ ] `/about` محدودهٔ خدمات را صریح می‌گوید.
- [ ] `/help` شامل ۵ گام «شروع سریع» با لینک واقعی است.
- [ ] `/help/safety` شامل علائم خطر و لینک به مسیر گزارش است.
- [ ] `/contact` هیچ اطلاعات تماس ساختگی ندارد.
- [ ] هیچ ادعای ضمانت مالی/پرداخت/ارسال مطرح نشده است.
- [ ] تست‌ها پاس و build سبز.
