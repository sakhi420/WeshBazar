# WeshBazar Homepage — Design Reference Assets

## مقصد
این فایل‌ها از تصویر مرجع ارائه‌شده برای بازسازی دقیق صفحهٔ نخست ویش‌بازار استخراج شده‌اند.

## محل استفاده در پروژه
- `reference/weshbazar-homepage-reference.png` → مرجع بصری کامل؛ آن را در ریپو در مسیر `docs/design-reference/weshbazar-homepage-reference.png` قرار دهید.
- `public/images/homepage/hero-art.webp` → تصویر هنری Hero؛ در `weshbazar-frontend/public/images/homepage/hero-art.webp` قرار دهید.
- `public/images/homepage/process-seller-art.webp` → تصویر فروشنده در بخش «چگونه کار می‌کند؟»؛ همان مسیر `public/images/homepage/`.
- `public/images/homepage/trust-shield-art.webp` → تصویر سپر در بخش اعتماد و احتیاط؛ همان مسیر.
- `public/images/homepage/cta-products-art.webp` → تصویر محصولات در بنر CTA پایانی؛ همان مسیر.

## محدودیت مهم
این فایل‌ها فقط تصویرهای هنری/تزئینی‌اند. از تصویر کامل مرجع به‌عنوان background صفحه یا یک تصویر تخت در وب‌سایت استفاده نکنید. تمام متن‌ها، دکمه‌ها، کارت‌ها، لینک‌ها، آیکون‌های کاربردی، Header و Footer باید با HTML/CSS/React واقعی ساخته شوند تا Responsive، قابل دسترس، قابل تعامل و قابل ترجمه باشند.
